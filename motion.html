Learn Motion

Understand movement, speed, distance and time.

📚 What is Motion?

Motion is the change in position of an object with time. An object is in motion when its position changes compared with a reference point.

🚗 Speed

Speed tells us how fast an object is moving.

Speed = Distance ÷ Time

📏 Distance

Distance is the total length of the path travelled by an object.

Example:

A car travels 100 km in 2 hours.

Speed = Distance ÷ Time
Speed = 100 ÷ 2
Answer = 50 km/h

⏱️ Time

Time tells us how long an object takes to complete a journey or activity.

🧠 Quick Summary

Motion means a change in position. Speed tells us how fast something moves. Distance tells us how far an object travels, while time tells us how long the movement takes.
