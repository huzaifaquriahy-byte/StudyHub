📚 What is an Element?

An element is a pure substance made of only one type of atom. Each element has its own unique properties.

🧪 Common Elements

Here are some elements that are important in everyday life and science.

H

Hydrogen

The lightest element.

O

Oxygen

Important for breathing.

C

Carbon

Found in living things.

📊 Periodic Table

The periodic table is a chart that organizes chemical elements according to their properties and atomic numbers.

Example:

Hydrogen has the symbol H and atomic number 1.

Oxygen has the symbol O and atomic number 8.

🔢 Atomic Number

The atomic number tells us the number of protons in the nucleus of an atom. Every element has a unique atomic number.

🧠 Quick Summary

Elements are pure substances made of one type of atom. The periodic table organizes the elements, and each element has a unique symbol and atomic number.
