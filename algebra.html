📚 What is Algebra?

Algebra is a part of mathematics that uses letters and symbols to represent unknown numbers.

🔤 Variables

A variable is a letter that represents a number. Common variables include x, y and z.

Example: x = 5

➕ Algebraic Expressions

An algebraic expression can contain numbers, variables and mathematical operations.

2x + 3
5y - 2
x + 10

✏️ Simple Equation

We can find an unknown number by solving an equation.

x + 5 = 10
x = 5

🧠 Algebra Quiz

What is x if x + 3 = 8?

What is x if x - 2 = 6?

What is 2x if x = 4?
