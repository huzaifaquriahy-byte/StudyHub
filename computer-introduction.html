Introduction to Computer

Learn the basic concept of a computer.

📚 What is a Computer?

A computer is an electronic machine that accepts data, processes it, stores it, and gives useful information.

⚙️ What Can a Computer Do?

A computer can perform many tasks such as calculations, writing documents, watching videos, playing games, storing information and accessing the internet.

🧠 Basic Computer Functions

The four basic functions of a computer are: Input, Processing, Output and Storage.

✏️ Example

When you type your name using a keyboard, the computer receives it as input, processes it and displays your name on the screen as output.
